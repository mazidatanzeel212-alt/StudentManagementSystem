
# Student Management System

A simple Student Management System developed using the C programming language.

## Features

- Add new student records
- View all student records
- Search students by ID
- Search students by name
- Update student information
- Delete student records
- Display student statistics
- Save and load records using file handling
- Validate duplicate student IDs

## Technologies Used

- C Programming
- GCC Compiler
- Ubuntu Linux (WSL)
- File Handling
- Structures
- Functions
- Arrays

## Project Structure

```text
StudentManagementSystem/
├── main.c
├── student.c
├── student.h
├── file.c
├── file.h
├── students.txt
└── README.md
```

## How to Compile

```bash
gcc -Wall -Wextra -std=c11 main.c student.c file.c -o student_management
```

## How to Run

```bash
./student_management
```
